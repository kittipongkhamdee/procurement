# ดีไซน์อ้างอิงที่ผู้ใช้ชอบ

ผู้ใช้ส่งลิงก์นี้มาเป็นตัวอย่างหน้าตาที่ชอบ ให้ใช้เป็นแรงบันดาลใจ/อ้างอิงเวลาปรับ UI ของระบบต่อไป
(ไม่ใช่ให้ทำตามทันที — บันทึกไว้เผื่อใช้ตอนถูกขอให้ปรับหน้าตาเพิ่มเติม)

- อ้างอิง: https://aiiapairoj.github.io/iso/index.html (ISO 27001 Compliance Suite — เดโม dashboard, สร้างด้วย Tailwind CSS)

## สิ่งที่น่าเอามาปรับใช้

**โทนสี (คล้ายกับที่ระบบเราใช้อยู่แล้ว — กรมท่า/น้ำเงิน):**
- Sidebar: gradient น้ำเงินเข้ม `#0B1F3F → #071630`
- Accent หลัก: ฟ้า `#2563EB` (hover เข้มขึ้นเป็น `#1D4ED8`)
- พื้นหลังหน้า: เทาอ่อนมาก `#F5F7FA`, เส้นแบ่ง `#E5E7EB`
- รองรับ dark mode เต็มรูปแบบ (สลับผ่าน `data-theme` + จำค่าไว้ใน localStorage)

**Sidebar:**
- กว้าง 236px ปกติ, ยุบเหลือ 66px แบบ icon-only ได้ (ปุ่ม toggle "mini mode")
- แต่ละเมนูมีไอคอน (Font Awesome) + label, เมนู active เป็นแท่งสีฟ้าเน้น พร้อมเงา
- มี footer เล็กในตัว sidebar (เครดิต/ลิงก์)

**Topbar:**
- ช่องค้นหาตรงกลาง (มี keyboard shortcut hint เช่น "⌘K" ทางขวาช่องค้นหา)
- ไอคอนแจ้งเตือนพร้อม badge ตัวเลข, ปุ่มสลับ dark/light
- โปรไฟล์ผู้ใช้มุมขวา: avatar วงกลม + จุดสถานะออนไลน์สีเขียว + ชื่อ/ตำแหน่ง

**หัวข้อหน้า (page header):**
- ชื่อหน้าใหญ่ + breadcrumb + คำอธิบายสั้น
- ฝั่งขวามี "stamp" (เวลาข้อมูลอัปเดตล่าสุด) + ปุ่ม refresh เล็กๆ

**KPI cards:**
- การ์ดเล็กเรียงเป็น grid (2-6 คอลัมน์ตามขนาดจอ) แต่ละใบมีไอคอนวงกลมสีต่างกันตามหมวด (ฟ้า/ส้ม/เขียว/ม่วง/เหลือง)
- ตัวเลขใหญ่ + label เล็กด้านล่าง, hover ยกการ์ดขึ้นเล็กน้อยพร้อมเงาเข้มขึ้น

**Panel/การ์ดเนื้อหา:**
- border-radius 12px, เส้นขอบบาง, เงาเบามาก
- หัวการ์ดมีเลขลำดับกำกับ (เช่น "1. Document Status Overview") + ลิงก์ "View All" มุมขวา

**ตาราง:**
- header พื้นเทาอ่อนมาก, แถว hover ไฮไลต์, badge สถานะสีพื้น+ขอบสีเข้ากัน (เช่น เขียวอ่อน/แดงอ่อน)
- มี pagination แบบปุ่มตัวเลข

**Mobile:**
- มี bottom tab bar แบบแอป (5 เมนูหลัก) แทนที่ sidebar บนจอมือถือ — ทางเลือกที่ต่างจาก hamburger overlay ที่เราใช้อยู่ตอนนี้ น่าพิจารณาถ้าอยากให้ใช้งานบนมือถือลื่นขึ้น

## หมายเหตุ

ธีมสีปัจจุบันของเรา (กรมท่า-ทอง) ใกล้เคียงกับต้นแบบนี้อยู่แล้ว (โทนน้ำเงินเข้ม sidebar) ส่วนที่ต่างชัดเจนคือต้นแบบนี้เน้นความ "dense/data-rich" แบบ dashboard องค์กรจริงจัง (ตัวอักษรเล็กกว่า, แน่นกว่า, มี dark mode, มี mini sidebar, มี command search) ซึ่งเหมาะกับระบบที่มีข้อมูลเยอะขึ้นเรื่อยๆ อย่างระบบนี้
